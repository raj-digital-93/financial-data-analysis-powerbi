# Financial Data Analysis – Power BI Dashboard

## Project Overview
This project is a Power BI financial analysis report built using a sample financial dataset.
The report focuses on analyzing Sales, Units Sold, and Profit across different Segments and Products to help stakeholders understand business performance and trends.

The dashboard is designed with separate pages for each key metric to ensure clarity, usability, and focused insights.

## Dataset
The dataset represents financial sales data with the following key fields:

Segment – Government, Business, Enterprise, Midmarket, Channel Partners

Product – Total 5 products

Sales – Revenue generated

Units Sold – Quantity sold

Profit – Net profit

(Other supporting fields as available in the sample data)

## Data Source
From the Power BI sample data

-> Power BI Desktop (Basic measures and visual-level filters)

## Key visuals used
-> Bar, Column & Area Charts
 
-> KPI cards

-> Slicers

-> Navigation

## Report Pages
  1. Sales Analysis
   
  Objective:
  Analyze revenue performance across segments and products.

  Key insights provided:

-> Analysis of total sales distribution across business segments

-> Revenue contribution analysis by segment to understand business dependence

-> Identification of high-performing and low-performing products based on sales trends

 2. Profit Analysis

 Objective:
 Evaluate profitability and margin efficiency.

 Key insights provided:

-> Profit by Segment and Product

-> Comparison between high-sales vs high-profit products

-> Identification of loss-making or low-margin segments

-> Profit contribution analysis by month

 3. Units sold Analysis

 Objective:
 Understand product demand and volume trends.

 Key insights provided:

-> Total Units Sold by Segment
 
-> Product-wise quantity comparison

-> Demand patterns across segments
